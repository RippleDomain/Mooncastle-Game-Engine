# Mooncastle

A 3D game engine I am currently working on.

### Features

| Category           | Description |
|--------------------|-------------|
| **ECS Architecture** | Powerful Entity-Component-System with ID tracking via index & generation. |
| **Custom Editor** | Built using WPF with scene hierarchy, multi-selection, and undo/redo. |
| **Project Management** | Create and load modular game projects with binary serialization. |
| **Lighting System** | Directional, point, and spot lights with tile-based light culling (Forward+). |
| **Input System** | Bind keys to control gameplay elements and camera movement. |
| **Scripting** | C++ scripting via DLL hot-reloading and script components. |
| **Asset Pipeline** | Import FBX files, compress textures, and generate PBR materials. |
| **Content Browser** | Visual asset manager with thumbnails, folder support, and drag-drop import. |
| **Material & Texture Editors** | View and manipulate textures, mip levels, and normal maps. |
| **Rendering** | DirectX 12 Forward+ pipeline with shadows, PBR, and post-processing. |
