# Mooncastle

A 3D game engine I am working on that will feature the following:

Modular Project System – Create, load, and manage game projects with scene-based structure.
Entity-Component System – Robust ECS with unique ID system using index + generation.
Custom Editor – WPF-based interface with multi-selection, undo/redo, message log, etc.
C++ Scripting Support – Script components with hot-reloaded game DLLs.
DirectX 12 Renderer – Forward+ rendering pipeline with PBR, shadow mapping, and post-processing.
Asset Pipeline – FBX import, texture compression, and binary asset serialization.
Content Browser – Visual asset manager with thumbnails, folders, and drag-and-drop import.
Texture & Mesh Editor – Custom tools for editing imported assets, mipmaps, and vertex attributes.
Input Handling System – Bindings and runtime control for player/camera interactions.
Light Management – Directional, point, and spot lights with tile-based light culling.
